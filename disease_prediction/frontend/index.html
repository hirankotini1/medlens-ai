ℹ️ About MEDLENS & ML Architecture

MEDLENS is a digital pathology laboratory management platform integrated with an experimental machine-learning decision-support backend. The platform provides end-to-end clinical workflow management—from patient registration and structured laboratory findings recording to automated multi-panel decision-support inference.

Key System Architectural Principles

  • Decoupled Report Architecture: Official laboratory findings remain immutable and authoritative. ML predictions are stored separately in an audit table and rendered in a distinct card.
  • Strict Security & IDOR Defenses: Cryptographic PBKDF2 password and PIN hashing, HMAC-signed session tokens, and strict role-based access control prevent cross-patient data leaks.
  • Five Validated Diagnostic Pipelines: Machine learning models for Anemia (Logistic Regression), Dengue (Random Forest), Liver Disease (Gradient Boosting), Thyroid Disorders (Multinomial Logistic Regression), and Malaria (Gradient Boosting + CV Color/Texture Extractor).
ℹ️ Regulatory & Research Boundary: This application is built for educational, academic, and decision-support research. It is not approved as a medical device for autonomous diagnosis.
